# Test screenshots

Orphan branch. It shares no history with `main` and holds no code.

One folder per test round: `YYYY-MM-DD-<round>/`, for example `2026-10-07-playwright-setup/`.
Each folder has the PNGs and a short `NOTES.md` (what was tested, against which `main` commit, what each picture shows).

Never commit a picture that shows a pairing link, token, invite code or other secret.
See `team/WORKING_RULES.md` on `main`, section "Self-testing".
