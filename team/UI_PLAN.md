# UI plan for the team layer (VISION.md step 3)

Picked 2026-10-07: Option C (Team home, "Today" when solo) with Option B's presence chip in the tab bar. Why: [DESIGN_DIRECTION.md](DESIGN_DIRECTION.md) section 5. One slice at a time; each ships on its own, self-tested in light and dark, solo and team.

Rules for every slice: one chip style reused everywhere (a person's or a chat's initials in one hue); words for anything that matters; nothing that repaints while idle; data pushed from the server, never polled by the browser; nothing added to the composer or message list render path that runs per keystroke.
